## 3. Test-command note (not a defect)
The guard test VcScheduler.style.test.ts reads process.cwd()/assets/styles/theme/colors.scss,
which resolves only when cwd = framework/. CI runs `yarn workspace @vc-shell/framework run test`
(cwd = framework/), so CI is green. The repo-root convenience script `yarn test:unit`
(`vitest --config framework/vitest.config.ts run`) uses the repo root as cwd and fails to collect
that file. All runs in this verification used the CI cwd.
