The bug & root cause

The VcSelect dropdown toggle rendered a raw <button> with bespoke vc-select__arrow styling, and VcMenuItem drew its focus ring with a fixed rounded radius and default offset — so the focus indicator did not match the control's button styling or the item's own corner shape.

PR #2411 swaps the chevron for the shared VcButton (ghost neutral, disabled wiring preserved, readonly still hides the arrow), and changes the menu-item focus to -outline-offset-2 + rounded-[inherit] so the ring follows each item's inherited radius. Two files: vc-select.vue, vc-menu-item.vue.
